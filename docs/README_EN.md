# TopStar2 Modifier

A GUI tool for patching `Assembly-CSharp.dll` in TopStar2. It supports automatic decryption of the original encrypted DLL, song and chart unlocks, item/note/coin/gem locks, timer freezing, skipping the tutorial, bypassing IO board checks, Free Play mode, touch & mouse input fixes, 120/240Hz high refresh rate & FPS unlocking, built-in FPS display, and an auto-return-to-Title fallback after game over.

Completely exit the game first, double-click `TopStar2修改器.bat`, and click **Browse** to select the game root directory.

See [USER_GUIDE.md](USER_GUIDE.md) for detailed instructions.
