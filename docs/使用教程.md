# TopStar2修改器 使用教程

整个文件夹要放在一起用，不要把里面的文件拆开。

修改目标文件为：

`游戏目录\Game\TopStar2_Data\Managed\Assembly-CSharp.dll`

勾选「修复触屏与鼠标」时，还会自动将 `PortableWindowsTouch.dll` 复制到 `游戏目录\Game\TopStar2_Data\Managed\` 目录。歌曲 `.pak` 文件无需改动。

这一份改动适用于当前版本游戏；重装或更新游戏后需重新应用。

---

## 一、打开与自动解密

1. 先**完全退出游戏**，再双击根目录的 `TopStar2修改器.bat`。
2. 软件采用无边框沉浸式高定顶栏（支持按住顶栏拖动、双击最大化/还原及右上角最小化/最大化/关闭），并提供**深色奢华（午夜星河）/ 浅色高贵（珍珠瓷白）**双主题一键切换（自动记住上次选择的主题偏好），以及 `English` / `中文` 界面语言切换（默认随 Windows 系统语言自动选择）。
3. 点「浏览」选择**游戏根目录**（或直接将游戏文件夹拖拽至窗口任意位置），修改器会自动定位 `Game\TopStar2_Data\Managed\Assembly-CSharp.dll` 并读取各项状态。
4. **原版加密 DLL 自动解密**：如果检测到 `Assembly-CSharp.dll` 仍为原版加密文件，修改器会自动将其备份为 `Assembly-CSharp.dll.bak`（若尚未存在），并短暂最小化启动一次 `Game\TopStar2.exe` 从内存中提取解密后的 DLL 写回磁盘，随后自动关闭游戏进程并读取状态。

> 需要本机安装 Python（官方安装包自带 Tkinter 窗口，无需额外安装第三方库）。若黑窗口提示 `Python was not found`，请安装 Python 并在第一页勾选 **Add python.exe to PATH** 后点 **Install Now**。

## 二、窗口功能说明

修改器采用左侧分类导航 + 右侧卡片详情布局，通过 `TopStar2Patcher.exe`（基于 `Mono.Cecil.dll`）在 IL 层直接读写 `Assembly-CSharp.dll`，各项均可通过右侧开关独立启用或关闭还原，左侧导航还支持「全选本页 / 清空本页」快捷操作。

### 1. 选歌与谱面

- **解除高级与大师谱面游玩限制**：高级无需先通关普通；大师无需通关高级或完成成就/任务。
- **离线也能选歌**：允许在离线状态下选择所有歌曲（对战和匹配找人仍需联网）。
- **解锁所有大师谱面**：大师列表中显示所有带大师谱面的歌曲（星级小于 0 的难度仍不出现）。

### 2. 物品与货币

- **音符全部解锁**：红、绿、蓝、箭头音符全部视为已解锁。
- **道具保持 999**：18 种常用道具使用时数量不减少，同时解除游客/离线模式下的道具使用限制。
- **金币保持 99999**：消费金币不会减少。
- **宝石保持 99999**：消费宝石不会减少。

### 3. 倒计时控制

开启开关后可自定义停住的秒数，关闭开关可还原为原版倒计时：

- **选歌**（`1`–`85` 秒，默认 `80`）：大于 85 秒时播放键不亮；到 0 会自动确认当前歌曲。
- **单人 / 对战 / 合作**（`1`–`600` 秒，默认 `10`）：到 0 会自动选单人。
- **旅程 / 任务 / 对战**（`1`–`600` 秒，默认 `99`）：到 0 会自动进入旅程。
- **音符和道具**（`1`–`600` 秒，默认 `20`）：音符选择与道具购买两步共用同一个倒计时；到 0 会自动进入下一步。
- **局内**（`1`–`999` 秒，默认 `90`）：画面停在设定秒数，不会因超时判定失败；谱面播放结束后仍正常通关结算。

### 4. 系统与高刷

- **高刷与高帧率**（`120Hz` / `240Hz` 分段切换）：在 `PreLoadResource.Start` 中关闭垂直同步（`QualitySettings.vSyncCount = 0`）并设置 `Application.targetFrameRate`，同时将 `Esc.SetFullScreen` 改为带目标刷新率参数的 `Screen.SetResolution(..., 120/240)`。因游戏内音符、判定与倒计时均基于真实时间（`Time.timeSinceLevelLoad` / `AudioSource.time` / `Time.deltaTime`）驱动，开启后可获得更流畅的高刷画面且不影响原有游戏速度。
- **显示内置 FPS**：在 `PreLoadResource.Start` 中初始化游戏内置的 `FPSCounter` 单例，在屏幕左上角常驻显示实时 `FPS:xxx`。
- **修复触屏与鼠标**：禁用框体串口/原始触摸接管，启用 Unity 鼠标与触屏输入（应用时会自动复制 `PortableWindowsTouch.dll` 到 `Managed` 目录）。
- **去IO检测**：跳过开机 IO 板串口检测，键盘 `F1` / `F2` 可分别模拟测试键（Test）与服务键（Service）。
- **免费投币**：强制开启免费游玩（Free Play），无需投币即可开始。
- **跳过教程视频**：对战、游客、新手旅程、离线开局不再播放教程视频，直接进入选歌。
- **游戏结束自动返回主菜单兜底**：在 `ContinueControl` 中加入基于 `Time.realtimeSinceStartup` 的真实时间兜底，20 秒未点击或进入返回流程后 4 秒卡死时强制返回 `Title` 场景。

## 三、应用与还原

- 切换任意开关后，点击右下角「**应用修改**」即可写入。
- 修改器会在首次写入前自动创建 `Assembly-CSharp.dll.bak`（若 `.bak` 已存在则不会覆盖，始终保留最初的备份）。
- 关闭某一项开关再点「**应用修改**」，可单独还原该项；也可以直接用 `Assembly-CSharp.dll.bak` 覆盖 `Assembly-CSharp.dll` 一键还原全部。
- 修改完成后重新启动游戏即可生效。

## 四、手动十六进制修改参考（仅针对已解密 DLL）

> 以下字节偏移仅适用于**未经过结构修改的已解密原版 `Assembly-CSharp.dll`**，供手动研究参考。日常使用建议直接通过界面勾选，由 `TopStar2Patcher.exe` 自动完成。

### 1. 高级、大师不再要求通关

`LockMusicControl.CheckLockType` 从文件位置 `0x3A190` 开始：

- `0x3A238`（`0x3A190 + 168`）：`18 2A` → `16 2A`（高级未通关原返回 2）。
- `0x3A24C`（`0x3A190 + 188`）：`19 2A` → `16 2A`（大师未解锁原返回 3）。

### 2. 离线也能选歌

- `0x3A20A`：`17 2A` → `16 2A`（周围字节 `28 5A 04 00 06 3A 02 00 00 00 17 2A`，只改末尾 `17`）。

### 3. 有大师谱面的歌出现在大师列表

- 过滤从 `0x3B9D8` 开始，第 12 字节 `0x3B9E4`：`02 7B` → `17 2A`。

### 4. 音符全部解锁

- `TopStarData.get_OpenAllMusicPermissions` 位于 `0x2ED4`：开头 `1A 7E D9 02 00 04 2A` 将第 2、3 字节改为 `17 2A`（即 `1A 17 2A`）。

### 5. 道具背包保持 999

每一处原为 8 字节（`1E 02 7B ... 04 2A`），整段改为 `1E 20 E7 03 00 00 2A 00`：

| 位置 | 道具 | 位置 | 道具 |
| --- | --- | --- | --- |
| `0xA3AF` | 单体护盾 | `0xA448` | 加速 3 |
| `0xA3C0` | 全能护盾 | `0xA459` | 加速 4 |
| `0xA3D1` | 时间护盾 | `0xA46A` | 经验道具 A |
| `0xA3E2` | 减速 1 | `0xA47B` | 经验道具 B |
| `0xA3F3` | 减速 2 | `0xA48C` | 经验道具 C |
| `0xA404` | 减速 3 | `0xA49D` | 经验道具 D |
| `0xA415` | 减速 4 | `0xA4AE` | 镜像横 |
| `0xA426` | 加速 1 | `0xA4BF` | 镜像竖 |
| `0xA437` | 加速 2 | `0xA4D0` | 镜像横竖 |

### 6. 选歌倒计时停在 80 秒

`MusicSelectControl.Update`（`0x3A677`，18 字节）：

- 原字节：`02 25 7B 49 09 00 04 28 5B 00 00 0A 59 7D 49 09 00 04`
- 改为：`02 22 00 00 A0 42 7D 49 09 00 04 00 00 00 00 00 00 00`（`<= 85` 播放键才会亮）

### 7. 跳过教程视频

将加载场景 `"Tutorial"`（`72 97 1B 00 70`）改为 `"Song_Select"`（`72 6B 07 00 70`），位置：`0x398E4`、`0x399C6`、`0x3BC6A`、`0x40990`。

### 8. 局内 90 秒倒计时停住

`TimeLimitManage.get_RemainTimeMs`（`0x2C150`，39 字节）：

- 原字节：`02 7B 6A 05 00 04 7E E3 05 00 04 7B E8 05 00 04 59 0A 20 B8 82 01 00 06 28 5F 00 00 0A 0A 06 16 3D 00 00 00 00 06 2A`
- 改为：`20 90 5F 01 00 2A 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00`
